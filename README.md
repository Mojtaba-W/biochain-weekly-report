BIOCHAIN Interactive Weekly Report — Week 01

FILES
- index.html: complete responsive website in one file (HTML, CSS, JavaScript).

PREVIEW
1. Extract the ZIP.
2. Double-click index.html to open it in Chrome/Edge.
3. Internet is needed for the LinkedIn post links.

PUBLISH FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository, e.g. biochain-weekly-report.
2. Upload index.html to the repository root (not inside another folder).
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait a few minutes. GitHub will show the public website URL in Settings → Pages.
